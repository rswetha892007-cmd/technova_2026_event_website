TECHNOVA 2026 – Event Landing Page

TECHNOVA 2026: Where Technology Meets Creativity

TECHNOVA 2026 is a modern, responsive event landing page designed to showcase a college technical event featuring innovation, coding, creativity, and technology.

The website provides event information, registration access, interactive features, and a unique Tech Personality Quiz to engage visitors.

Features

- Responsive Design: Adapts to desktop and mobile screens.
- Interactive Navigation: Navigate easily between website sections.
- Event Registration: Register through an integrated Google Form.
- Countdown Timer: Displays the time remaining until the event.
- Dark/Light Mode: Switch between visual themes.
- Tech Personality Quiz: Discover your tech persona by answering five questions.
- Personalized Results: Receive a technology persona and relevant recommendations.
- Quiz Progress Bar: Track progress through the quiz.
- Copy Quiz Result: Copy your result to share with others.
- Retake Quiz: Restart the quiz at any time.
- Interactive Event Highlights: Explore additional information about event highlights.
- FAQ Accordion: Expand and collapse frequently asked questions.
- Preparation Checklist: Track event preparation tasks.
- Copy Event Details: Copy important event information.
- Back-to-Top Button: Return quickly to the top of the page.
- Scroll Progress Indicator: Track scrolling progress.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Forms

How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Explore the website and test its interactive features.

No additional installation is required.

Project Objective

The objective of this project is to create an engaging event landing page while demonstrating practical knowledge of HTML, CSS, JavaScript, DOM manipulation, event handling, and interactive web development.

Unique Feature

The Tech Personality Quiz helps visitors discover their technology persona through five interactive questions. Based on their answers, the website displays a personalized result and recommendations.
